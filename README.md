# Anas QABBAL — Systems that do not break

Static Next.js portfolio with a terminal-style command interface. There is no backend, API, AI, or environment configuration.

## Setup

```bash
npm i
npm run dev
npm run build
```

The production build is exported to `out/` with `output: "export"` and can be deployed to Vercel or GitHub Pages.

## Deploy

For GitHub Pages, use the included Actions workflow and set the repository Pages source to **GitHub Actions**. Vercel detects the Next.js app automatically.
