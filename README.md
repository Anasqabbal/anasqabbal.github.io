# Anas QABBAL portfolio

Static terminal-style portfolio built with Next.js, TypeScript, and Tailwind CSS. All command responses are local data; there is no backend, API route, AI, or environment configuration.

## Setup

```sh
npm i
npm run dev
```

Create a production static export with:

```sh
npm run build
```

The generated site is written to `out/`.

## Deploy

Deploy `out/` to Vercel as a static Next.js project, or publish the contents of `out/` to GitHub Pages. The project uses `output: "export"` and does not require a Node server.
